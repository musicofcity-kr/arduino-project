# Profile — 과학교육 프로그램

`core/`는 도메인 중립이다. 이 파일은 과학교육 산출물에만 적용되는 **추가 P0와 추가 검증 항목**을 정의한다. (관측 실패 F7: 도메인 조항이 범용 본문에 섞여 재사용을 방해했다)

---

## 1. 추가 P0 (사전규칙, a priori)

전부 비가역 위해에 해당하므로 실패 경험 없이 즉시 채택한다.

| 코드 | 규칙 |
|---|---|
| `SE-P0-1` | 과학적 사실 오류를 산출하지 않는다. 불확실한 값은 출처를 밝히거나 표시하지 않는다 |
| `SE-P0-2` | 검증되지 않은 추정(이미지 인식, LLM 생성 등)을 학생에게 사실로 확정 제시하지 않는다 |
| `SE-P0-3` | 학생 개인정보는 기본적으로 저장·전송하지 않는다(기본값 = 비식별·최소수집). 예외는 `PROJECT_SPEC.md` front matter `personal_data: collected`와 `## 12. Data Handling`의 purpose/items/retention/access/external_transfer 5개를 모두 채운 경우에만 성립하며, **`check_package.py`의 `C26`이 이를 강제한다** |
| `SE-P0-4` | 계산 좌표·실측값·모형 좌표를 UI와 데이터에서 분리하고 출처를 표기한다 |
| `SE-P0-5` | 탐구·서술 활동을 근거 없이 자동 정오 판정해 채점하지 않는다. 객관식·정형 형성평가 자동채점은 `auto_grading: declared`와 `## 12. Data Handling`의 assessment_purpose/answer_basis/feedback_path 3개를 채운 경우에만 허용하며, **`C26`이 이를 강제한다** |
| `SE-P0-6` | 시뮬레이션의 가정과 실제 현상의 차이를 명시한다 |
| `SE-P0-7` | 오개념을 강화할 수 있는 표현·시각화를 사전 점검한다 |
| `SE-P0-8` | 실험 절차 포함 시 안전 유의사항을 누락하지 않는다 |

---

### 1.1 예외 조항 설계 원칙

`SE-P0-3`과 `SE-P0-5`는 **비가역 위해에 대한 사전규칙**이다 (`core/CONSTITUTION.md` §5.1).
사전규칙을 조건부로 완화할 때는 그 조건이 **기계로 판정 가능해야 한다.**
판정되지 않는 예외는 예외가 아니라 규칙의 삭제다.

## 2. 오개념 점검 절차

산출물 배포 전 다음을 통과한다.

1. **표상 점검** — 시각화가 실제 물리·화학적 사실과 다른 인상을 주지 않는가 (예: 평면 표현이 평면 구조로 오인되는가)
2. **조작-개념 연결** — 학생의 조작이 학습 목표 개념과 실제로 연결되는가. 조작이 재미만 주고 개념과 무관하면 제거 대상이다
3. **단위·스케일** — 임의 픽셀·화면 좌표가 물리량(Å, °, mol 등)으로 오독될 여지가 없는가
4. **정답 제시 시점** — 학생이 스스로 관찰·기록하기 전에 정답 형태명이나 수치를 먼저 노출하지 않는가

## 3. 교육과정 정합

- 적용 교육과정(예: 2022 개정)과 대상 과목·성취기준 코드를 `PROJECT_SPEC.md`에 명시한다
- 성취기준에 없는 내용을 임의로 추가하지 않는다. 추가할 경우 심화·선택으로 명시 구분한다
- 평가 요소를 넣을 경우 루브릭 근거를 함께 기록한다

## 4. 추가 Definition of Done (human-checked)

- [ ] 과학적 사실 검증 (출처 명시)
- [ ] 오개념 점검 4항목 통과
- [ ] 학습 목표와 학생 조작의 연결 확인
- [ ] 시뮬레이션 가정·한계 표시 확인
- [ ] 개인정보 처리 경로 확인
- [ ] 실환경(실기기·학교망·실제 학생) 미검증 범위 명시

## 5. 릴리스 등급 (과학교육 전용)

`core`의 증거 등급 위에 얹는 배포 범위 구분이다. **자동 테스트 통과만으로 상위 등급을 주지 않는다.**

| 등급 | 조건 |
|---|---|
| `prototype` | 로컬 실행 확인 |
| `verified-build` | 자동 테스트 + 빌드 통과 (V2) |
| `controlled-pilot` | 교사 1인이 통제된 환경에서 완주 (V3 일부) |
| `classroom-tested` | 실제 수업에서 학생 사용 관찰 + 사전·사후 기록 확보 (V3) |
| `published` | 위 전부 + 외부 검토 |

> `verified-build` 상태를 `classroom-tested`로 표기하는 것은 **P0 위반**으로 취급한다.
