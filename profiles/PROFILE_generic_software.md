# Profile — 일반 소프트웨어

과학교육 외 프로젝트(관리 도구, 데이터 파이프라인, 업무 자동화 등)에 적용한다.

## 1. 추가 P0 (사전규칙)

| 코드 | 규칙 |
|---|---|
| `GS-P0-1` | 개인정보·자격증명을 코드·로그·커밋에 남기지 않는다 |
| `GS-P0-2` | 삭제·덮어쓰기 연산은 되돌릴 수 있거나 사전 확인을 거친다 |
| `GS-P0-3` | 외부 API 실패 시 조용히 잘못된 값을 반환하지 않는다 (fail-closed) |
| `GS-P0-4` | 마이그레이션은 롤백 경로를 함께 만든다 |

## 2. 추가 Definition of Done

- [ ] 오류 경로 테스트 존재 (성공 경로만 있는 스위트는 미완)
- [ ] 로그에 민감정보 미포함 확인
- [ ] 되돌리기 절차 문서화
- [ ] 의존성 버전 고정

## 3. 릴리스 등급

| 등급 | 조건 |
|---|---|
| `prototype` | 로컬 실행 확인 |
| `verified-build` | 자동 테스트 + 빌드 통과 |
| `internal` | 제작자 외 1인 이상 실사용 |
| `production` | 실환경 운영 + 롤백 절차 검증 |
