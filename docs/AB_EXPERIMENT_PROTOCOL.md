# 대조 실험 프로토콜 — "통제량과 산출물 품질" 검증

## 왜 필요한가

현재 이 패키지의 핵심 가설은 다음과 같다.

> **H1**: 통제를 실패 비용이 비가역인 영역에 한정하고 나머지를 자유 영역으로 예약하면, 전 영역을 통제하는 경우보다 산출물 품질이 높다.

관측 근거는 Physical Molecule Scanner 1건뿐이며 대조군이 없다. 현재 상태는 **예비 관찰(pilot observation)** 이지 검증이 아니다. 이 문서는 그 간극을 메우는 최소 설계다.

관측된 지지 신호(약함, 표본 1):
- 최대 품질 개선(UX 리디자인, desktop stage 1462px→897px)이 **Freedom Zone 내부**에서 발생
- 통제 영역에서 나온 것은 결함 수리(fetch≠render)였고 품질 상승이 아님
- 방향은 일치하나 대조군이 없어 인과 주장 불가

## 1. 설계

**독립변수**: 통제 방식 3수준

| 조건 | 처치 |
|---|---|
| A. 최소 통제 | 목표와 P0만 제시, 구현 자유 |
| B. **선택적 통제** (본 패키지) | P0~P3 계층 + Freedom Floor + Control Budget |
| C. 전면 통제 | 파일 구조·컴포넌트 분할·구현 방식까지 사전 지정 |

**종속변수**: 아래 §2 지표

**과제**: 동일 난이도의 교육용 시뮬레이션 3종. 서로 독립적이고 사전 지식이 겹치지 않아야 한다. 예: (a) 기체 분자 운동, (b) 산-염기 적정 곡선, (c) 결정 격자 배위수.

**배치**: 라틴방격(3×3). 과제와 조건의 교락(confounding)을 제거한다.

| | 과제 a | 과제 b | 과제 c |
|---|---|---|---|
| 세션 1 | A | B | C |
| 세션 2 | B | C | A |
| 세션 3 | C | A | B |

**고정 조건**: 동일 모델·동일 버전, 동일 시간 상한, 동일 도구, 동일 사람. 세션 간 학습 전이를 줄이기 위해 과제 순서를 무작위화한다.

## 2. 측정 지표 (사전 정의 — 실험 후 변경 금지)

| 지표 | 정의 | 수집 방법 |
|---|---|---|
| M1 기능 정확성 | 사전 작성한 수용 기준 통과율 | 자동 테스트 |
| M2 과학적 정확성 | 오류 건수 (사실·단위·표상) | 교사 2인 독립 검토 |
| M3 P0 위반 | 위반 건수 | 체크리스트 |
| M4 사용성 | 첫 사용자가 핵심 작업 완료까지 걸린 시간 | 학생 5인 관찰 |
| M5 오개념 위험 | 오개념 유발 가능 요소 건수 | 교사 2인 독립 검토 |
| M6 초과 산출 | **요구하지 않았으나 유용한 기능·개선의 수** | 교사 2인 합의 |
| M7 재작업량 | 수정 라운드 수, 누적 diff 라인 | 로그 |
| M8 소요 시간 | 착수~완료 | 로그 |

> **M6이 핵심 지표다.** H1이 참이면 조건 B·A에서 M6이 높고 조건 C에서 낮아야 한다. M1~M3(하한)은 B·C에서 비슷하고 A에서 낮아야 한다.
>
> 예측: **B가 "M1~M3 높음 + M6 높음"을 동시에 만족하는 유일한 조건**이다. A는 M6은 높지만 M3(P0 위반)에서 실패하고, C는 M3는 안전하지만 M6이 낮다.

## 3. 편향 통제

현재 기록의 최대 약점은 **처치 설계자와 결과 채점자가 동일인**이라는 점이다. 다음을 반드시 적용한다.

1. **맹검 채점** — 채점자는 어느 산출물이 어느 조건인지 모른다. 산출물에서 조건 식별 단서(주석, 파일명, 커밋 메시지)를 제거한 뒤 무작위 순서로 제시한다.
2. **채점자 2인 이상** — 일치도(Cohen's κ 또는 단순 일치율) 보고. κ < 0.6이면 기준을 재정의하고 재채점한다.
3. **사전 등록** — 실험 시작 전 이 문서의 §2를 확정하고 수정하지 않는다. 사후에 지표를 바꾸면 결과는 무효다.
4. **제3자 실행 1세트** — 가능하면 제작자가 아닌 교사 1인이 동일 프로토콜을 반복한다.

## 4. 표본과 검정력

- 최소: 3조건 × 3과제 = 9세션 (탐색적, 통계 검정 불가)
- 권장: 3조건 × 3과제 × 3반복 = 27세션 (조건당 9, 비모수 검정 가능)

9세션 결과는 **기술통계와 사례 기술로만 보고**하고 유의성 주장을 하지 않는다. 27세션 확보 시 Friedman 검정 + 사후 Wilcoxon 부호순위 검정을 적용한다.

## 6. 실패 조건 (미리 정한다)

다음 중 하나면 H1을 기각하거나 수정한다.

- 조건 C의 M6이 B와 통계적·실질적으로 차이가 없다 → 자유도가 초과 산출을 만들지 않는다
- 조건 B의 M1~M3이 C보다 낮다 → 선택적 통제가 하한을 지키지 못한다
- 채점자 일치도가 반복적으로 낮다 → 지표 정의 실패, 실험 재설계

> 기각 조건을 미리 쓰지 않은 실험은 확증 편향을 피할 수 없다.
